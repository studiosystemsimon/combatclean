★ New order-reward type: the LIMIT ENERGY CHEST

The real mechanics: fulfilling a normal order grants a gear chest + a small limit-energy drip (~0.48 to every hero), and a tier-3+ merge drips limit energy too. A hero's limit break needs 5 to charge — so a normal order is only ~10% of a charge: far too small to be a satisfying first lesson. The Limit Energy Chest exists to make "deliver → unleash" land in one beat.

What — an order whose reward is a large slug of LIMIT ENERGY to your hero (instead of a gear chest), enough to fully (or nearly) charge their limit break on the spot.

Why — it's the payoff that teaches the whole point of merging/ordering: orders feed your limit → the limit wipes the screen.

How it plugs in (to build)
  • Orders gain a reward type: gear (default, existing) | limitEnergy (new).
  • FULFILL_ORDER branches: gear → the current chest; limitEnergy → grant limitChestFrac × limitEnergyToCharge (config, e.g. 1.0 = full) to the fulfilling hero (or squad), + a distinct chest VFX flying into the limit bar.
  • The orders rail renders the limit-energy chest with its own icon (a charged-battery / bolt chest), so it reads as "different reward".
  • How it's offered: rare roll in rollOrder later; for the FTUE the first order is authored as a limit-energy chest (deterministic seed).

Implementation notes (for wiring later)

  1. Build the Limit Energy Chest first. The whole opening hinges on it (steps 6–7). New order reward type + the FULFILL_ORDER branch + rail icon + a config limitChestFrac. See the spec box above.
  2. Deterministic FTUE seed. On a fresh save, seed the board + author the first order as a limit-energy chest whose request = exactly the tile the two forges + one merge produce. The tutorial can never roll an unfulfillable / wrong-reward first order.
  3. One schedule, persisted flags. Each beat has a trigger + a one-shot seen flag (persisted). Steps 1–12 = the run-once guided opening; 13–20 fire when their condition first occurs.
  4. GATE = input mask. During a gate, dim + block everything except the coached target (spotlight + hand icon); NUDGE only highlights.
  5. Limit break is now core, not deferred. It's the payoff of the very first lesson (step 7), so its own coachmark lives there — there is no separate "later" limit-break beat.
  6. Teach on demand. Energy (10), Heroes/gear (14), Summon (15), cobwebs (17) each fire the moment the player hits the problem they solve — never as upfront rules. GEAR (the normal order reward) is taught at step 14, when it first matters.
  7. Reuse existing systems. Coachmarks ride the existing overlay/FX layer and the existing popups (AFK, area-complete, limit-charge motes) — no parallel tutorial renderer, no parallel reward path (the limit-energy chest is a new branch of the SAME order-reward system).
