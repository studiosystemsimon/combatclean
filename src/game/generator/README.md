# generator — generator tiles — tap cost, per-level weighted drops onto the board

**Invariants** — pure functions; reads config via `../content.ts` (`C`); any randomness comes from an injected `rng`. No DOM, no game numbers as literals (all tuning is config). Generators are LEVELLED (0-based, mirroring item tiers): drops come from `C.GENERATORS[genId].dropsByLevel[level]`, and `maxGenLevel(genId)` = that array's length − 1 (the top level index). `rollDropLevel(genId, level, rng)` selects the level's table (undefined/legacy level → treated as 0). A level-L generator never drops a tier above L (the per-level tables are ceiling-capped in data). Levelling itself (two same-level generators merging up) lives in the `merge` module + reducer, not here.
